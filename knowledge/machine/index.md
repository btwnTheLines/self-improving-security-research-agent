# Machine Knowledge — Entry

Token-efficient class entries for model consumption.

- Only load the modules activated by the router: `knowledge/index.md`.
- Format per entry: `ID · WHEN · SURFACE · OBSERVE · HYPOTHESIS · TEST · ADAPT ·
  CONFIRM · IMPACT · STOP · TOOLS · RELATED` (fields omitted when not useful).
- Entries structure and route the model's existing knowledge; they do not teach
  security, and they never authorize an action.
- Payload construction: a general process, not a dictionary — see
  `human/universal-security-testing-playbook.md` (§ Test-input generation) and the
  `machine` entries' `TEST`/`ADAPT` fields.

Modules: `injection` · `client` · `authentication` · `authorization` · `web` ·
`files` · `api` · `business-logic` · `configuration` · `protocol` ·
`modern-apps` · `cloud`.
